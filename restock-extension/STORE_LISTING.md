## 商店資訊（Store listing）

**名稱**：補貨通知 for Weverse Shop（來自 `manifest.json`）

**摘要**（132 字以內，來自 `manifest.json` 的 description）：
定時檢查 Weverse Shop 商品頁，指定的選項從售完變成有貨時跳出桌面通知。不需登入、不蒐集任何資料。

**說明**：

```
想買的周邊總是秒殺？加入商品頁，選好要等的選項，補貨的那一刻就跳出桌面通知。

■ 功能
・同時監測多個商品，每個商品可以只盯特定選項（例如某位成員），或全部選項
・補貨時跳出通知，點一下直接打開商品頁
・工具列圖示上的數字＝目前有貨的監測選項數量；讀取失敗會顯示紅色驚嘆號
・自動處理地區限定商品（依網址幣別判斷國家，也可以手動指定）
・同一個選項補貨後有冷卻時間，不會一直重複通知
・可以暫停個別商品、匯入／匯出監測清單

■ 使用方式
1. 打開擴充功能的設定頁，貼上商品頁網址，按「讀取選項」
2. 勾選要監測的選項（或全部），按「加入監測」
3. 保持 Chrome 開著就好，預設每 5 分鐘檢查一次

■ 注意
・只有 Chrome 開著時才會檢查；電腦睡眠或 Chrome 關閉期間不會監測
・沒有看到通知的話，請確認作業系統允許 Chrome 顯示通知

■ 隱私
所有資料只存在你的瀏覽器裡。擴充功能只會讀取你加入的 shop.weverse.io 商品頁，不連到任何其他伺服器，沒有分析或追蹤。

本擴充功能為個人開發，與 Weverse、HYBE 無任何關係，也未獲其授權或背書。
```

**類別**：購物（Shopping）
**語言**：中文（繁體）

## 隱私權做法（Privacy practices）

**單一用途說明**：
監測使用者指定的 Weverse Shop 商品頁庫存，在選項從售完變成有貨時顯示桌面通知。

**權限理由**：

| 權限 | 填寫內容 |
|---|---|
| alarms | 依使用者設定的間隔（預設 5 分鐘）定時檢查商品頁庫存。 |
| storage | 在本機儲存使用者的監測清單、設定與上次看到的庫存狀態，用來判斷是否「從售完變成有貨」。 |
| notifications | 商品補貨時顯示桌面通知，這是本擴充功能的主要功能。 |
| declarativeNetRequestWithHostAccess | 地區限定商品需要帶國家 cookie 才會回傳庫存資料。此規則只套用在擴充功能自己的背景請求（tabId = -1），不影響使用者瀏覽的分頁。 |
| 主機權限 https://shop.weverse.io/* | 讀取使用者加入的商品頁 HTML，解析其中公開的庫存資訊。只限此網域。 |
| 遠端程式碼 | 否。所有程式碼都包在擴充功能裡，不載入或執行任何遠端程式碼。 |

**資料使用**：全部不勾（不蒐集任何使用者資料），並勾選三項聲明：
- 不會將使用者資料出售或轉移給第三方（核准用途除外）
- 不會將使用者資料用於與單一用途無關的目的
- 不會將使用者資料用於判斷信用或放款

**隱私權政策網址**：`PRIVACY.md` 公開後的網址（見 README「發佈到 Chrome Web Store」）。

## 發佈設定（Distribution）
