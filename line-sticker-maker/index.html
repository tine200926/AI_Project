LINE 貼圖快速製作

一次拖入多張圖片 → 自動去背、裁切、加白邊 → 依 LINE 規格輸出 ZIP（貼圖、main.png、tab.png）。所有處理都在你的瀏覽器內完成，不會上傳圖片。

設定

自動偵測圖片四周的顏色當作背景。
白邊顏色
四周保留 10px 留白，寬高自動調成偶數。
LINE 貼圖規格
  • 貼圖：最大 370×320 px、PNG、透明背景、寬高偶數、每張 1MB 以下
  • 數量：8 / 16 / 24 / 32 / 40 張
  • 主要圖片 main.png：240×240 px
  • 聊天室標籤 tab.png：96×74 px
  • 檔名 01.png、02.png… 依順序排列
拖曳圖片到這裡，或點擊選擇 支援 PNG / JPG / WebP，可一次多張；也可直接 Ctrl+V 貼上
尚未加入圖片
加入圖片後會在這裡預覽。點「設為主圖」選擇 main.png / tab.png 的來源（預設第一張）。
