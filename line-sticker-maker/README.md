# LINE 貼圖快速製作

單一 HTML 網頁：一次丟入多張圖片 → 去背 → 裁切、加白邊 → 依 LINE Creators Market 規格打包成 ZIP。
所有處理都在瀏覽器內完成，圖片不會上傳到任何伺服器。

## 使用方式

直接用瀏覽器打開 `index.html`（或放到 GitHub Pages 等任何靜態網站）。

1. 選擇去背方式
   - **AI 自動去背**：照片、複雜背景。第一次會下載約 40MB 模型（之後瀏覽器有快取），每張數秒。
   - **背景色去除**：白底／純色背景的插圖，瞬間完成。可調容許度，勾選「也移除被包住的同色區塊」可去掉手臂間等封閉空隙。
   - **不去背**：圖片本來就是透明 PNG。
2. 拖曳多張圖片進來（也可點擊選擇或 Ctrl+V 貼上）。依檔名自然排序，可用 ◀ ▶ 調整順序。
3. 每張卡片可個別切換去背方式、重做、移除，並選一張「設為主圖」。
4. 調整白邊粗細／顏色、陰影、尺寸時會即時套用到全部貼圖（不需重新去背）。
5. 按「下載貼圖 ZIP」。

## 輸出內容

| 檔案 | 規格 |
|---|---|
| `01.png` … `40.png` | 最大 370×320、寬高偶數、四周 10px 留白、透明 PNG |
| `main.png` | 240×240（取自主圖） |
| `tab.png` | 96×74（取自主圖） |

LINE 上架需 8 / 16 / 24 / 32 / 40 張，張數不符時頁面會提示；每張超過 1MB 也會標紅。
