# 優惠券定時領取 for 賣貨便（Chrome 擴充功能）

在指定的時間自動打開 [7-ELEVEN 賣貨便「領取優惠券」頁](https://myship.7-11.com.tw/mem/GetCoupon)，
**對準網站的時間**重新整理，然後一直點「領取」按鈕，直到全部領完或時間到，最後跳出桌面通知告訴你結果。

> 為什麼不用 `.bat`？領券需要你的登入狀態，而且要在頁面上點按鈕；`.bat` 只能幫你「打開網頁」，
> 沒辦法在登入後的頁面裡點擊。擴充功能直接在你已登入的 Chrome 裡執行，最穩。

## 安裝（免費，不用上架）

1. 下載這個 repo（綠色 **Code → Download ZIP** 後解壓縮，或 `git clone`）。
2. Chrome 打開 `chrome://extensions`，右上角打開 **開發人員模式**。
3. 按 **載入未封裝項目**，選 `coupon-extension` 資料夾。
4. 會自動打開設定頁。
5. 先到 [賣貨便](https://myship.7-11.com.tw/) **登入**。

## 使用方式

1. 設定頁 →「新增排程」：
   - **指定日期一次**：例如 `2026-11-11` `10:00:00`。
   - **每天／每週固定時間**：例如每天 `12:00:00`，或只勾週一、三、五。
2. 時間到前 60 秒（可調）會自動把優惠券頁開到最前面，右上角有倒數。
3. 到點時重新整理，開始點「領取」。網站跳出的「確定要領取嗎？」會自動按確定，「領取成功」等訊息會記在紀錄裡。
4. 所有領取按鈕都變成「已領取」後自動停止，並跳出通知。

**建議先按一次「立即執行一次」**，確認登入正常、按鈕找得到（它會真的去按領取）。

## 設定說明

| 設定 | 預設 | 說明 |
|---|---|---|
| 提前幾秒打開頁面 | 60 | 先開好頁面、校正時間 |
| 到點後持續嘗試 | 60 秒 | 這段時間內一直嘗試，時間到就停 |
| 同一顆按鈕重按間隔 | 500 ms | 按了還沒變成「已領取」就再按 |
| 找不到按鈕時重新整理間隔 | 3000 ms | 到點了頁面還沒出現「領取」就重新整理 |
| 提早幾毫秒動作 | 0 | 網路比較慢可以設 100～300 |
| 到點時重新整理頁面 | 開 | 優惠券多半要重新整理才會出現可領的按鈕 |
| 用網站時間校正 | 開 | 讀網站回應的 `Date` 時間，修正電腦時鐘誤差（通常可校正到 ±100 ms 內） |
| 自動按「確定」 | 開 | 原生 `confirm/alert` 與頁面上的彈出視窗都自動確定 |
| 只領名稱包含這些字的券 | 空白 | 例如 `免運, 50元`；空白＝全部都領 |
| 領取按鈕的文字 | `領取,立即領取,領券,領取優惠券` | 網站按鈕文字不同時可以改 |
| 不要按的按鈕文字 | `已領取,已領完,…` | 含這些字的按鈕不會按 |
| 進階：CSS 選擇器 | 空白 | 找不到按鈕時，可以直接指定（例如 `.coupon-item .btn-get`） |

## 注意事項

- **Chrome 要開著、電腦不要睡眠**。關掉 Chrome 後再打開，如果還在「持續嘗試」的時間內，仍會補執行。
- 執行時優惠券分頁會切到最前面；請不要把視窗縮到最小，Chrome 會降低背景分頁的計時精準度。
- 沒登入會跳出「需要先登入賣貨便」通知。
- 本工具只是替你在自己的帳號上按按鈕，請遵守網站的使用規範，不要把間隔設得太短。

## 檔案

| 檔案 | 用途 |
|---|---|
| `manifest.json` | Manifest V3 設定 |
| `background.js` | Service worker：排程（`chrome.alarms`）、開分頁、紀錄、通知 |
| `content.js` | 在優惠券頁上執行：網站時間校正、倒數、到點重新整理、找按鈕並點擊 |
| `hook.js` | 在頁面環境中接管 `confirm()` / `alert()`（只在執行期間） |
| `lib/core.js` | 排程計算、按鈕文字判斷、時間校正等純函式（可用 node 測試） |
| `popup.*` / `options.*` | 工具列小視窗、設定頁 |
| `tests/` | 單元測試與 Playwright 端對端測試 |
| `tools/` | 產生圖示、打包 zip |

## 測試

```bash
node --test tests/core.test.mjs
```

```bash
node tests/e2e.mjs
```

`e2e.mjs` 用 Playwright 攔截 `myship.7-11.com.tw` 的請求、提供一個假的優惠券頁（時鐘比電腦快 1.5 秒），
把真正的擴充功能載進 Chromium，驗證：排程觸發、依網站時間到點重新整理、開放前不會亂按、
自動確認對話框、只領指定名稱的券、按鈕沒出現時重新整理、停止按鈕、未登入偵測、每日排程。

## 打包

```bash
python3 tools/pack.py
```

會產生 `dist/coupon-extension-<版本>.zip`，可以分享給別人或上架 Chrome Web Store。
