# 虎航低價機票搜尋（Chrome 擴充功能）

設定目的地、來回或單程、旅遊天數、可以旅遊的期間和預算，一次查完整段期間，列出**符合條件、最便宜**的台灣虎航出發／回程日期組合，點「去訂票」直接帶著日期打開虎航訂票頁。

- 可以一次勾**多個目的地**（例如整個日本），一起比價，上方卡片顯示每個目的地最便宜的一組。
- 來回：可旅遊期間 = 最早出發日～最晚回程日，整趟旅程都會落在期間內；旅遊天數可以是範圍（例如 3～5 天）。
- 天數含出發和回程當天：**5 天 = 5天4夜**，1 天 = 當天來回。
- 價錢是**每人**；來回 = 去程 + 回程合計。留空表示不限。
- 可以限制**出發星期**（例如只看週四～週六出發）。
- 表單會記住，下次打開還在。同樣的查詢 10 分鐘內再按一次直接用快取，不會重查。

非台灣虎航官方產品，只讀虎航網站上任何人都看得到的票價，不需要登入、不會訂票、不蒐集任何資料。

## 安裝（自己用，不用上架）

1. 下載或 `git clone` 這個資料夾。
2. Chrome 打開 `chrome://extensions`，右上角打開「開發人員模式」。
3. 按「載入未封裝項目」，選 `tigerair-finder` 資料夾。
4. 會自動打開搜尋頁；之後點工具列上的圖示（綠底飛機）就會開新分頁。

## 怎麼查的

虎航官網的低價日曆用一支公開的 JSON API 回傳「每天最低的單程票價」：

```
GET https://api-cms.tigerairtw.com/api/app/book/daily-prices
    ?origin=TPE&destination=KIX&userCurrency=TWD&pricingCurrency=TWD
    &since=2026-12-01&until=2026-12-31
→ {"data": [{"date": "2026-12-01", "amount": 1799, ...}, ...]}
```

1. 依你的條件算出每個方向需要的日期範圍。來回最少 N 天的話，去程最晚只要查到「最晚回程日 − (N−1)」，回程最早從「最早出發日 + (N−1)」開始，用不到的日子不查。
2. **按月份切開**請求，每個目的地 × 去／回程 × 月份各一個，同時最多 3 個。
3. `amount` 是 0 或沒有值的日子當成沒航班／售完。API 偶爾會多回範圍外的日子，一律丟掉。
4. 每個符合星期條件的出發日 × 每個天數，找到回程那天的價格，加總、套用價錢範圍，再由便宜到貴排序。

目的地清單會先問虎航「這個出發地有飛哪些地方」（`api-book.tigerairtw.com/api/general/available-destinations`），只列出有飛的航點；這支 API 掛掉時會列出內建的全部航點，沒飛的航線查詢時會顯示「沒有航班」。清單裡沒有的新航點可以在「其他機場代碼」直接輸入。

擴充功能發出的請求會把 `Origin`／`Referer` 設成虎航自己的網站（`declarativeNetRequest` 規則，只套用在這個擴充功能自己發出的請求，不影響你平常瀏覽虎航）。

## 限制

- **價格是低價日曆上的單程最低票價**，可能未含稅金、行李、選位等費用，也隨時會變；實際金額以虎航訂票頁為準。點「去訂票」後在虎航頁面上確認。
- 這是虎航網站內部使用的 API，不是公開給第三方的服務，虎航改版時可能會失效。出現「查詢失敗」時：
  1. 先確認瀏覽器能正常打開 tigerairtw.com（排隊頁、維護中都會讓查詢失敗）。
  2. 在搜尋頁按 F12 → Network，看 `daily-prices` 請求的狀態碼與回應內容。回應格式改了的話，要改的地方在 `lib/core.js` 的 `parseDailyPrices`。
- 一次查很多目的地 × 很長的期間會發出比較多請求（例如 10 個目的地 × 6 個月 × 2 方向 = 120 個），需要十幾秒；查太頻繁可能被虎航暫時限制（HTTP 429），等一下再查即可。

## 檔案

| 檔案 | 用途 |
|---|---|
| `manifest.json` | Manifest V3 設定 |
| `background.js` | 點工具列圖示／第一次安裝時打開搜尋頁 |
| `search.html` / `search.js` / `styles.css` | 搜尋頁：表單、進度、結果表格 |
| `lib/core.js` | 日期計算、表單檢查、請求規劃、解析 API 回應、組合來回行程（不依賴 Chrome API，可用 node 測試） |
| `lib/api.js` | 呼叫虎航 API、重試、逾時、10 分鐘快取、請求標頭規則 |
| `lib/stations.js` | 內建航點清單（中文名稱、國家分組） |
| `tests/` | `core.test.mjs` 單元測試、`e2e.mjs` 用 Playwright 載入擴充功能跑完整流程 |
| `tools/make_icons.py` | 產生圖示 |

## 測試

```bash
node --test tests/core.test.mjs
```

```bash
node tests/e2e.mjs
```

`e2e.mjs` 把真正的擴充功能載進 Chromium，用模擬的虎航 API 回應（不連網）驗證：安裝時打開搜尋頁、依航線清單過濾目的地、標頭規則只作用於本擴充功能、表單檢查、來回多目的地最便宜組合（與獨立的暴力解比對筆數和最低價）、按月份切請求、訂票連結、顯示更多與排序、快取、價錢上限、重開後記住表單、單一航線失敗時的警告、每個目的地都有月份失敗時仍列出其餘結果、單程、航線清單掛掉時的退路、全部失敗時的錯誤訊息。加 `--screenshots <資料夾>` 會存下畫面截圖。
